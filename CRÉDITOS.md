# Créditos e licenças do conteúdo

- **Nova Bíblia de Acesso Livre (NVA)**: CC BY-SA 4.0. Fonte: Door43; arquivo SQLite obtido do projeto [Projeto-Euaggelion/biblia.publica](https://github.com/Projeto-Euaggelion/biblia.publica). O texto não foi editado; foi convertido para o formato offline do app. [Licença CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- **Almeida 1911**: domínio público. Fonte e declaração de licença: [Projeto-Euaggelion/biblia.publica](https://github.com/Projeto-Euaggelion/biblia.publica), arquivo `versoes/alm1911/LICENSE.md`; fonte upstream indicada: `damarals/biblias`.
- **Bíblia Portuguesa Mundial (BPM)**: domínio público. Fonte: [eBible.org, PORBSL](https://ebible.org/details.php?id=porbrbsl), edição de 2026-10-08. O texto é um rascunho em revisão.
- **Tradução literal do original (OWB-L)**: CC0. Fonte: [Open Word Bible](https://openwordbible.org/pt/download/).
- **Bíblia Livre (versão online)**: atribuição requerida; licença e dados da edição na [eBible.org](https://ebible.org/Scriptures/details.php?id=porbr2018). Disponibilizada pela [Free Use Bible API / AO Lab](https://bible.helloao.org/docs/pt/).
- **Biblica Open Nova Bíblia Viva 2007 (versão online)**: licença e atribuição conforme os dados da edição na [eBible.org](https://ebible.org/Scriptures/details.php?id=poronbv). Disponibilizada pela [Free Use Bible API / AO Lab](https://bible.helloao.org/docs/pt/).

Os textos locais foram reunidos em `static/content/bible-data.js` para uso offline. As versões online são obtidas como tradução completa e guardadas no IndexedDB do navegador após o primeiro acesso. A API e o código do serviço são MIT; cada tradução mantém sua licença e aviso próprios. A NVI não está disponível nessa API e não foi incluída; uma integração NVI depende de autorização específica da editora.

A pronúncia e o agrupamento visual são recursos de estudo; o corpus não fornece alinhamento palavra a palavra entre o original e o português.
